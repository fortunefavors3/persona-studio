# Persona Studio

A safe-for-work generator for fictional, clearly AI-generated social media characters. It creates a persona, a consistent look guide for image tools, and a week or 30 days of captions with image prompts.

## Features

- 8 niches: lifestyle, fitness, combat sports, fashion, travel, food, tech, gaming
- Platform formats for Instagram, TikTok, and YouTube
- Voice and aesthetic options, 3/5/7 posts per week, 1-week or 30-day plans
- AI disclosure line on captions (on by default)
- History saved in the browser (search, niche filter, side-by-side compare)
- Copy buttons and Markdown export

## Running it

It is a single file: open `index.html` in a browser, or enable GitHub Pages on this repo.

## AI features

"Generate with AI", "Rewrite with AI", and the file-save dialog only work when the page is hosted inside Claude (published as a Claude artifact). Everywhere else, the template generator, history, compare, copy buttons, and Markdown export (copied to clipboard) still work.

## Content policy

This tool produces family-friendly content only. It does not include and will not be extended with sexually explicit or suggestive options.
